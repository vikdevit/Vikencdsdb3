Analyse de données structurées par l'IA (machine learning)    

Les données ont été analysées à l’aide du machine learning non supervisé.  L’approche combine une réduction de la dimensionnalité par analyse en composantes principales (ACP) et un algorithme de clustering de type k-means pour regrouper les données selon leur similarité.
